# Security

Do not include private biological data, credentials, or personal information in
public issues. Use a minimal synthetic input when reporting parser bugs.

For a suspected vulnerability, use GitHub's private vulnerability reporting
option if it is available. Otherwise open a public issue requesting a private
contact channel without disclosing exploit details or sensitive data.

This initial version has no long-term support commitment. Security fixes, when
available, will be documented in the changelog. Keep your Python interpreter
updated and process untrusted files within appropriate resource limits.

# Roadmap

## Available in 0.1.0

- Strict DNA FASTA validation, gzip and stdin input.
- Base counts, GC, ambiguity, N, lowercase, and length statistics.
- Deterministic JSON, TSV and Markdown reports.
- Warning thresholds, exit codes, tests, and cross-platform CI.

## Candidate improvements

These are proposals, not implemented features or commitments.

- Independent comparison of metrics with established bioinformatics tools.
- JSON Schema file and compatibility tests for downstream consumers.
- Optional JSON Lines output for datasets with many records.
- Benchmarks documenting input sizes, hardware, time, and peak memory.
- Optional separate RNA mode with explicit alphabet and metric rules.

Before broadening scope, prioritize real bug reports and feedback from users.
